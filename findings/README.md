# Findings

Generated by `python -m attacks --agent both --out findings` (also `make demo-attacks` and `make retest`).

| File | What it is |
|---|---|
| `vulnerable.json` / `vulnerable.md` | Attack suite vs the over-privileged copilot |
| `hardened.json` / `hardened.md` | Same suite vs the control plane |
| `retest.md` | Side-by-side pass/fail |

`COMPROMISED` on the vulnerable agent is the intended educational result.
`BLOCKED` on the hardened agent is the intended retest result.

Audit JSONL lands in `sandbox/logs/` (gitignored). Mock emails land in `sandbox/outbox/` (gitignored).
